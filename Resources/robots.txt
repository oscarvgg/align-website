# NOTE: Disallow prevents crawling, not indexing. Search Console confirms the

# them out of the index would need an X-Robots-Tag: noindex header, which in
# turn needs crawlers to be allowed to fetch the file and a host that can set
# response headers. The current static host cannot, and these files draw 0
# clicks in the latest 28 days, so this stays as-is deliberately.
